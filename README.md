# Sistema Taller

Aplicación web de gestión para talleres y servicios técnicos.

Stack: React + TypeScript + Tailwind CSS + shadcn/ui + Supabase.

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`
- `npm test`

## Estructura

- `src/` frontend
- `supabase/migrations/` esquema y RLS
- `docs/` documentación por módulo
