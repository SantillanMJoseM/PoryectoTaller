# Evaluación de Riesgos - Sistema Taller

Niveles: A (bajo), B (medio), C (alto/crítico).
- Operaciones de lectura: Nivel A.
- CRUD de clientes/productos: Nivel B.
- Facturación y movimientos financieros: Nivel C (requiere aprobación).
- Gestión de usuarios/permisos: Nivel C.
- Eliminación de datos: Nivel C.
Controles: RLS en Supabase, permisos por rol, auditoría, validación frontend/backend.
